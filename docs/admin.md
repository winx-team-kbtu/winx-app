# Панель администратора Winx

Панель открывается по адресу `/admin`. Войдите под существующим аккаунтом с ролью `admin`. Для выдачи роли оператор базы может выполнить в PostgreSQL следующий запрос, подставив адрес нужного аккаунта.

```sql
UPDATE users
SET role_id = (SELECT id FROM roles WHERE slug = 'admin')
WHERE email = 'operator@example.org' AND deletion_requested_at IS NULL;
```

Во вкладке «Данные» доступны поиск, просмотр, создание, изменение и удаление 22 типов записей. Каталог включает анкеты MongoDB и данные PostgreSQL о пользователях, ролях, знакомствах, командах, чатах и уведомлениях. Связи задаются идентификаторами записей. Для аккаунтов пароль вводится отдельным полем. При удалении аккаунта используется штатная процедура удаления данных из нескольких хранилищ.

Журнал показывает администратора, действие, тип записи, ключ и время изменения. Журнал доступен для чтения, служебные токены и секреты OAuth остаются за пределами панели.

Сводка использует сохранённые действия приложения. Дни и сравниваемые периоды рассчитываются по часовому поясу Алматы. Активные пользователи — уникальные авторы учтённых действий. В табличном представлении под графиком доступны точные значения каждого дня.
